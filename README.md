# THE AFTER

เกมเล่าเรื่องมุมมองบุคคลที่หนึ่ง ทำด้วย Unity 6

---

## เปิดโปรเจกต์บนเครื่องใหม่

### 1. ลงของสามอย่างนี้ก่อน

| ของ | เวอร์ชัน | หมายเหตุ |
|---|---|---|
| **Unity** | **6000.5.0f1** เป๊ะ ๆ | ลงผ่าน Unity Hub เวอร์ชันอื่นจะ upgrade โปรเจกต์แล้วอาจพัง |
| **Git** | อะไรก็ได้ | https://git-scm.com |
| **Git LFS** | อะไรก็ได้ | https://git-lfs.com — **สำคัญที่สุด อ่านข้อ 2** |

### 2. ต้องลง Git LFS ให้เสร็จ *ก่อน* โคลน

โมเดล เสียง เท็กซ์เจอร์ ฟอนต์ ทั้งหมดราว 800 MB เก็บด้วย Git LFS
ถ้าโคลนโดยยังไม่ได้ลง LFS จะได้แค่ไฟล์ข้อความสั้น ๆ ที่ชี้ไปหาของจริง
โปรเจกต์จะเปิดขึ้นมาแบบโมเดลหายหมด และ**ไม่มีอะไรบอกว่าผิด**

```bash
git lfs install
```

รันคำสั่งนี้ครั้งเดียวต่อเครื่อง แล้วค่อยโคลน

### 3. โคลน — วางไว้ใกล้รากไดรฟ์

บน Windows ให้โคลนลงที่อยู่สั้น ๆ เช่น `C:\THE-AFTER`

```bash
cd /c
git clone https://github.com/wachirahatchui-dotcom/THE-AFTER.git
```

ประมาณ 800 MB รอสักพัก

> **อย่าโคลนลงโฟลเดอร์ที่ชื่อยาวหรือซ้อนกันลึก** เช่นใน Downloads ที่ซ้อนอีกหลายชั้น
> ไฟล์ในแพ็กเกจของ Unity บางไฟล์ path ยาวเกือบ 120 ตัวอักษรอยู่แล้ว พอรวมกับ
> ที่อยู่ของโฟลเดอร์จะทะลุขีด 260 ตัวอักษรของ Windows แล้ว git จะ checkout ค้าง
> กลางคัน ได้โปรเจกต์ที่ไฟล์หายเป็นพัน ๆ ไฟล์ (เคยเจอมาแล้วตอนทดสอบ)

> **อย่าใช้ปุ่ม "Download ZIP" ของ GitHub**
> ZIP ไม่มีเนื้อไฟล์ LFS ได้มาจะเป็นโปรเจกต์ที่โมเดลหายหมด ต้อง `git clone` เท่านั้น

### 4. เช็คว่าได้ของจริงครบ

```bash
git lfs ls-files | wc -l
```

ต้องได้ **269** ถ้าได้ 0 แปลว่าข้อ 2 ยังไม่เรียบร้อย แก้ด้วย

```bash
git lfs install && git lfs pull
```

### 5. เปิดใน Unity

Unity Hub → **Add** → เลือกโฟลเดอร์ `THE-AFTER`

เปิดครั้งแรกจะช้ามาก (10–30 นาที) เพราะ Unity ต้องสร้างโฟลเดอร์ `Library/`
ใหม่ทั้งหมด — import โมเดล บีบอัดเท็กซ์เจอร์ คอมไพล์เชเดอร์ ครั้งต่อไปจะเร็วปกติ

### 6. กดเล่น

เปิดซีน `Assets/Scenes/MainMenu.unity` แล้วกด Play

## ซีนในเกม

| ซีน | คืออะไร |
|---|---|
| `Assets/Scenes/MainMenu.unity` | เมนูหลัก จุดเริ่มของเกม |
| `Assets/Scenes/Chapter1.unity` | บทที่ 1 ทั้งบท — Stage 1 (ห้องนอน) → Stage 2 (บังเกอร์) → Stage 3 (โรงรถ) |
| `Assets/Scenes/Sandbox.unity` | ที่ทดลอง รวมทุกอย่างไว้ ไม่ใช่ซีนที่เกมใช้จริง |

Chapter1 แบ่งของเป็นชุดตาม stage (`=== Stage 1 Set ===` ฯลฯ) เปิดทีละชุด
ชุดที่ยังไม่ถึงจะถูกปิดไว้ ไม่กินเครื่อง
